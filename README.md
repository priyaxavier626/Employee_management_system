# Employee Management System

## 📌 Project Overview
This is a desktop application developed using Python, Tkinter, and SQLite. It helps users manage employee records efficiently.

## ✨ Features
- Add Employee
- Search Employee
- Update Employee
- Delete Employee
- View Employee Details

## 🛠 Technologies Used
- Python
- Tkinter
- SQLite

## ▶️ How to Run
1. Download or clone the repository.
2. Install Python 3.
3. Run:
   ```
   python main.py
   ```
